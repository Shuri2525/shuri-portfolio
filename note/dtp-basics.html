01
# 出力

画面どおりに印刷できるのはなぜ？

データを「完成した絵」ではなく「描き方の指示書」として送るから。プリンタ側が指示書を読んで、その機械でいちばんきれいに描きます。

プリンタは4つの方式がある

インクを吹きつける、トナーを紙に移す、ピンで叩く、熱でインクを気体にして染める。ふだん「◯◯プリンタ」と呼ぶのは、この印字方式の違いです。

どこで「絵」にするかが違う

昔のやり方（Mac の QuickDraw、Windows の GDI）は、パソコンで印刷用の画像を作ってから送るので、重くて粗くなりがちでした。PostScript は「この位置にこのフォントで」という指示書を送り、プリンタ内の RIP が描きます。だから機械が変わっても同じ結果になり、高性能な機械ほどきれいに刷れます。

指示書はPostScriptからPDFへ

DTP は PostScript から始まりましたが、いまの印刷所では PDF をそのまま処理する RIP（Adobe PDF Print Engine）が主流です。

NOW入稿は PDF/X-4 での書き出しが推奨。透明効果（ドロップシャドウや乗算）を分割せずに渡せます。

DTPが印刷の現場を変えた

昔は写植、製版など、工程ごとに高価な専用機と専門の職人が必要でした。PostScript と Illustrator・Photoshop・レイアウトソフト、それに対応フォントがそろい、デザイナーが画面で仕上がりを見ながら作れるように。日本では文字数の多さが壁でしたが、和文フォントが増えるにつれて広まりました。

02
# 色

なぜ印刷はCMYKのインキを使うの？

光（RGB）は重ねると白に、インキ（CMY）は重ねると黒に近づきます。紙に刷るのはインキなので CMY、そこに黒（K）を足した4色です。

光の三原色とインキの三原色

モニタは光そのものなので、赤・緑・青の光を足して色を作ります（加法混色）。紙は光を反射して見える色なので、インキで光を吸い取って色を作ります（減法混色）。黒い物が黒く見えるのは、光をほとんど吸ってしまうからです。

黒（K）を足す理由

理屈では CMY を混ぜれば黒になりますが、実際のインキは純粋な色ではないので、にごった茶色にしかなりません。そこで黒インキを足します。K は Black の頭文字ではなく、仕上がりを引き締める「Key（カギ）になる版」から来ています。

濃淡は「点の大きさ」で出す

濃さごとにインキを用意するのは無理なので、インキは1色1濃度のまま、点（網点）の大きさで濃淡を表します。点が十分小さいと、人の目には点ではなく色の濃さに見えます。各色の網点は角度をずらして刷り、半透明のインキが重なって色が混ざります。

CMYKでは出せない色もある

モニタで見える鮮やかな緑（例：R50 G255 B0）やオレンジ、蛍光色は、CMYK の範囲（色域）の外。そのまま刷るとくすみます。どうしても必要なら、DIC や TOYO の特色インキをスポットカラーとして指定します。

03
# 出力

印刷線数と解像度、なにが違うの？

写真の解像度は「使うサイズのままで350dpi」が目安。これは印刷の網点の細かさ（175線）の2倍、という決まりから来ています。

dpiは「1インチに何マスあるか」

dpi・ppi は1インチ（2.54cm）あたりのピクセル数。72dpi なら1マスは1/72インチ、144dpi なら半分の大きさです。数字が大きいほどマスが小さく、曲線のギザギザ（ジャギ）が目立たなくなります。

拡大するときの注意

サイズと解像度の比率を保てば画質は落ちません（10×15cm・400dpi → 20×30cm・200dpi）。Photoshop の［イメージ］→［画像解像度］で「再サンプル」をオフにして変えます。オンのまま拡大すると、ないピクセルを推測で埋める（補間）のでぼやけます。縮小や解像度を下げる方向は、実用上ほぼ問題ありません。

NOWPhotoshop 2026 には AI で解像度を上げる「生成アップスケール」もあります。使ったら必ず原寸で仕上がりを確認しましょう。

「線数の2倍」というルール

人の目は約250dpiあればピクセルを見分けられないと言われますが、網点できれいに再現しやすく、計算もしやすいので「線数×2」が目安になりました。ソフトの画面写真のように72dpiでも十分な場合もあれば、低すぎてぼやける場合もあるので、配置サイズで判断します。

3つの「細かさ」の違い

  • 出力解像度（dpi）：出力機が打てる一番小さな点の細かさ
  • 網点：その点を何個も集めて作る、濃淡用の点（ハーフトーンセル）
  • 印刷線数（lpi）：1インチに網点が何個並ぶか

出力解像度が高いほど、細かい網点となめらかなグラデーションが作れます。

04
# 色

画面の色と印刷の色が違う！

カメラ、モニタ、プリンタは、出せる色の範囲がそれぞれ違います。プロファイルという「通訳」を通して色を受け渡すのが、カラーマネジメントです。

機器ごとに出せる色が違う

「赤」と言っても、思い浮かべる赤は人それぞれ。機械も同じで、取り込める色・表示できる色・刷れる色の範囲（カラースペース）がばらばらです。そこで、人の目を基準に色を数値で表す CIE 表色系を土台に、機器の違いを埋めるしくみが作られました。

プロファイルは色の通訳

ICC プロファイルは「この機器はこういう色を出す」と書いた説明書。2つのプロファイルを見比べて色を変換するのが CMM で、Adobe のアプリには ACE が入っています。変換で大事なのは、元データの正しいプロファイルで開き、正しい出力先を指定することの2つだけです。

まずは機器を整える

どんなに正しく変換しても、モニタやプリンタの発色がずれていたら意味がありません。発色を基準に合わせる作業がキャリブレーション。目で合わせるツールもOSにありますが、厳密にやるなら測色器を使い、その機器専用のプロファイルを作ります。

いまのやり方

昔は「RGB のプロファイルは埋め込む、CMYK は埋め込まない」が基本でした。印刷の色の基準（Japan Color、雑誌広告基準カラー JMPA）ができてからは、最終的な刷り先のプロファイルを埋め込むのが推奨。校正用プリンタは、埋め込まれたプロファイルを見て自分の色に自動で変換して出力します。

NOWAdobe の入稿ガイドでは Japan Color 2011 Coated を基準にしています。カラー設定は Bridge でアプリ間をまとめて同期できます。

05
# 文字

フォントのアウトライン化はもう古い？

いまは OpenType フォントで作って PDF/X-4 で入稿するのが基本。アウトライン化は、印刷所に指定されたときや最後の保険として使います。

昔の悩み：フォントがそろわない

昔の PostScript フォントは、作る側のパソコンと出力機の両方に同じフォントが必要でした。デザイン会社と印刷会社で環境が違うと、別の書体に置き換わったり、文字組みが崩れたりします。同じ書体でも形式（OCF・CID）が違うだけで詰め方が変わるトラブルもありました。

アウトライン化の良いところ・困るところ

文字を図形に変えるので、フォントがない環境でも同じ形で出せます。ただし、

  • あとから文字を直せない
  • 小さい文字をくっきり見せる「ヒント情報」が消える
  • レイアウトソフトの長文では組みが崩れやすい

作業用データはテキストのまま残し、入稿用だけアウトライン化するのが安全です。

OpenTypeで悩みが解決

  • 使う文字の形だけを毎回プリンタへ送る（ダイナミックダウンロード）ので、出力機にフォントがいらない
  • 解像度の制限がなく、高解像度の出力でもきれい
  • PDF に埋め込める、アウトライン化もできる
  • Unicode ベースで最大約6万5千字、Mac・Windows 共通

いまの注意点

NOW古い Type 1（PostScript）フォントは、Photoshop 23.0・Illustrator 27.3・InDesign 18.2 以降では使えません。古いデータを開くと「フォントがありません」になるので、OpenType に置き換えます。

Adobe Fonts で作ったデータは、印刷所によって「アウトライン化」か「PDF/X-4」のどちらかを指定されることがあります。入稿前に印刷所の案内を確認しましょう。

06
# レイアウト・製本

黒をオーバープリントするのはなぜ？

印刷ではほんの少しのズレが避けられず、色の境目に白いすき間が出ることがあります。黒い小さな文字は、下の色を抜かずに上から重ねて刷る（ノセ）と防げます。

ふだんの印刷はオフセット

本やチラシのほとんどはオフセット印刷。版の絵柄の部分は油（インキ）をはじかず、それ以外は水になじむ性質を使います。先に水、次にインキを付けると、絵柄だけにインキが乗ります。それを一度ゴムの胴に移してから紙に刷るので、「オフセット（移して刷る）」と呼びます。

他に、凸版（活版）、凹版（グラビア）、孔版（シルクスクリーン）があります。

刷る順番は K→C→M→Y

4色は1色ずつ、乾ききらないうちに重ねて刷ります。先の色がはがれたり混ざったりしないよう、膜がうすくて粘りの強い黒から刷るのが基本。紙全体をベタで塗る場合などは、Y→M→C→K のように順番を変えることもあります。

広い面を黒くしたいときは、K100%だけより C30＋K100 などのリッチブラックのほうが深い黒になります。

すき間を防ぐ2つの方法

  • ノセ（オーバープリント）：下の色を抜かずに上から刷る。インキは半透明で下の色が透けるので、透けても目立たないK100%の小さい文字に使います
  • トラッピング：隣り合う色の片方を少し広げて重ねる。淡い色を広げるのがチョーク、濃い色を広げるのがスプレッド

仕上がりは画面で確認

オーバープリントは、ふつうの表示では見た目が変わりません。

NOWIllustrator・InDesign では［表示］→［オーバープリントプレビュー］と［ウィンドウ］→［出力］→［分版プレビュー］で確認できます。書き出した PDF は Acrobat Pro の「出力プレビュー」でもチェックできます。

# レイアウト・製本

仕上がりより大きい紙で刷るのはなぜ？

はみ出させた色（塗り足し）とトンボまで一緒に刷ってから、余分を切り落とすからです。A4の原稿なら、ひと回り大きいB4やA3ノビの紙を使います。

塗り足しは3mm

紙の端まで色や写真を入れるときは、仕上がり線より3mm外まで伸ばしておきます。断裁がほんの少しずれても、紙の白が見えないようにするためです。忘れると印刷所から差し戻されることもある、大事な処理です。

トンボの役割

四隅の角トンボは仕上がりと塗り足しの位置を示し、断裁（化粧裁ち）の目印になります。各辺の中央のセンタートンボは、4色を重ねて刷るときの位置合わせ（見当合わせ）用。印刷所によっては、色の確認用パッチや日付なども一緒に刷ります。

紙のサイズの決まり

A判・B判は JIS の規格。数字が1つ増えるごとに面積が半分になります。紙の厚さは「原紙1,000枚の重さ」で表します（例：110kg）。

A判（mm）B判（mm）
3297×420364×515
4210×297257×364
5148×210182×257

面付けでコストが変わる

印刷機では、大きな紙に同じ原稿をいくつも並べて刷り、あとで切り分けます（面付け）。塗り足しがあると間にすき間が必要になり、1枚に並べられる数が減って、コストに響くことがあります。

校正用にトンボ付きで出すときも同じで、A3の原稿はA3より少し大きい「A3ノビ」の紙が必要です。

08
# レイアウト・製本

版面とマージンってなに？

版面（はんづら）は、本文や写真を置く範囲のこと。デザインはまず版面を決めて、その外側を安全な余白にします。

版面の大きさで印象が変わる

紙に対する版面の割合（版面率）が大きいと、情報がたくさん入ってにぎやかに。小さいと余白が増えて上品に見えます。ページ番号（ノンブル）や柱は版面の外に置くのが一般的。アクセントとしてわざと写真をはみ出させることもあります。

余白は最低5〜8mm

紙は機械の中でつかんで送るので、端には刷れない部分があります。さらに、刷ったあとは何百枚も重ねて一気に切るため、上と下の紙で切れる位置が少しずれます。文字は仕上がり線から5〜8mm（名刺など小さいものは3〜5mm）内側に置きましょう。

ページの多い本は「のど」を広く

小説のように厚い本は、綴じ側（のど）が開ききらず、余白が狭いと文字が読みにくくなります。のど側の余白を広めにとり、見開きにまたがる写真は、綴じで隠れる部分をずらして配置します。

文字中心の本は計算で決める

横の長さ文字サイズ×1行の字数
縦の長さ（行数−1）×行送り＋文字サイズ

例：A4横組み、12Q・行送り20H、58字×51行（1Q＝1H＝0.25mm）なら、横174mm・縦253mm。中央に置けば左右18mm・天地22mmの余白です。

NOWInDesign 2026 は［新規ドキュメント］で「レイアウトグリッド」を選ぶと字数・行数から自動で版面を作れます。Illustrator は自分で計算してガイドを引きます。

09
# レイアウト・製本

本のページ数はどうやって決まる？

大きな紙の表と裏に8〜16ページ分ずつ刷って、折りたたんで本にします。だからページ数はたいてい8か16の倍数になります。

折るたびにページが倍に

紙1枚を半分に折ると4ページ。これが本の最小単位です。90度回してもう一度折ると8ページ、さらに折ると16ページ。印刷は表裏に刷るので、片面に8面並べれば1枚で16ページ分になります。縦組みの本は右綴じ、横組みは左綴じが基本です。

綴じ方でページの並びが変わる

32ページの本の場合、平綴じは1〜16ページと17〜32ページの折を順に重ねます。中綴じは折を開いて入れ子にするので、外側の折に1〜8と25〜32、内側に9〜24が入ります。間違えないよう、折った紙にページ番号を書いた見本（折り丁）で確認します。

上製本と並製本

  • 上製本（ハードカバー）：厚紙の表紙でくるむ丈夫な作り。辞書や記念本に。手間とコストはかかる
  • 並製本（ソフトカバー）：雑誌やパンフレットに。安価だが長期保存には弱め

綴じ方は、針金で留める中綴じ・平綴じ、背を接着剤で固める無線綴じ（背に切れ目を入れるアジロ綴じも）、糸で縫う糸綴じがあります。

開きやすさを考えて余白をとる

ページ数が多いと、綴じ方による開きにくさが目立ちます。中綴じは紙の厚みで中ほどのページが外へ飛び出すので、開く側（小口）の余白を広めに。針金の平綴じは綴じしろで奥が見えなくなるので、綴じ側の余白を広めにとります。

10
# 文字

読みやすい文章はどう組む？

目立たせて手に取ってもらっても、本文が読みにくいと途中でやめられてしまいます。読む人を疲れさせない字数・大きさ・行間を選びましょう。

1行の字数

短すぎると改行のたびに目が戻る回数が増え、長すぎると次の行頭を探しにくくなります。どちらも疲れの原因に。

縦組み20〜45字
横組み15〜35字

文字サイズ・字間・行間

本文の大きさ11〜14Q（8〜10pt）
行送り（縦組み）文字の1.5〜2倍
行送り（横組み）文字の1.5〜1.75倍

字間は、詰めた組みより等間隔のベタ組みのほうが視線のリズムが一定で疲れにくい。高齢の方や子ども向けは大きめにします。

書体とウェイト

明朝体（欧文ならセリフ体）は線に強弱と「うろこ」があり、長文でも疲れにくい。ゴシック体（サンセリフ体）は線が均一で、元気な印象になります。同じ書体の太さ違い（ファミリー）で本文・小見出し・大見出しを作ると統一感が出ます。小さい文字に太い書体を使うと、刷ったときに潰れやすいので注意。

図版は紙面の半分くらい

写真やイラストがあると、目を引きつけ、読みにくさも和らぎます。広告や雑誌では図版の面積を50%前後にすると読みやすいと言われます。多すぎると情報が入りきらず、幼い印象にも。小説のように図版がない場合は、余白・文字サイズ・行間でぎっしり感を減らします。

11
# 色

インキの沈みってなに？

紙がインキを吸い込んで、色が暗く濃く見えること。表面加工のない上質紙などで起きやすいので、色を淡めに指定したり、専用のプロファイルで変換したりして先回りします。

塗工紙と非塗工紙

  • 塗工紙（アート紙・コート紙など）：表面に白い顔料を塗った紙。発色が良く写真向き。ツヤのあるグロス系と、落ち着いたマット系がある
  • 非塗工紙（上質紙・新聞・本の本文など）：インキを吸いやすく発色は控えめだが、反射が少なく目にやさしいので文字中心の本に向く

上質紙では色を淡めに

紙がインキを吸うと、色がくすんで暗く、濃く見えます。これがインキの沈み。非塗工紙は塗工紙より20〜30%濃く見えると言われるので、文字や図の色はイメージより20%ほど淡く指定すると、思った色に近づきます。鮮やかな特色ほど沈みが目立ちます。

写真は紙に合ったプロファイルで変換

写真を RGB から CMYK にするとき、刷る紙に合ったプロファイルを選ぶと、同じ写真でも CMYK の数値が変わり、沈みを見込んだ色になります。Photoshop の［編集］→［プロファイル変換］で変換先を指定します。既存のプロファイルがない場合は、インキの総量やドットゲインを調整して変換する方法もあります。

もっと広い色を刷るには

CMYK にオレンジとグリーンを足す6色印刷や、ふつうの4色より色域の広いインキ（東洋インキの kaleido、DIC の湧水など）があります。どれも専用のプロファイルで変換するのが前提。鮮やかな特色を確実に出したいときは、本番と同じ紙とインキで色校正をとるのが一番です。
